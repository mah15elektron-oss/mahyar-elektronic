# Mahyar Elektronic — پروژهٔ وب

این پروژه یک پایهٔ قابل توسعه برای سایت فارسی Mahyar Elektronic است: فرانت‌اند واکنش‌گرا، نمونهٔ پنل مدیریت، API ابری Cloudflare Worker، پایگاه داده D1 و فضای فایل R2.

## مهم: دمو در برابر سایت آنلاین
- پوشهٔ `public/` بدون سرور اجرا می‌شود و برای مشاهدهٔ طراحی مناسب است.
- پنل در حالت دمو با رمز `ME-demo-2026` کار می‌کند و محتوا را فقط در مرورگر فعلی ذخیره می‌کند. **این رمز برای سایت عمومی امن نیست.**
- برای انتشار واقعی، باید API را deploy کنید، رازهای مدیر را در محیط ابری تنظیم کنید، D1/R2 بسازید و `API_BASE` را در `public/app.js` تنظیم کنید. تا این کارها انجام نشده، سایت عمومی و پنل امنِ آنلاین محسوب نمی‌شود.

## امکانات پیاده‌سازی‌شده
- طراحی RTL فارسی و واکنش‌گرا
- جست‌وجو و فیلتر دسته‌بندی
- نمایش مقاله و محتوای نمونه
- پنل دمو برای ایجاد، ویرایش و حذف مطالب
- رابط بارگذاری تصویر/ویدئو/PDF/ZIP به فضای R2 پس از اتصال API
- بنر رضایت کوکی و تنظیمات آمار
- API برای فهرست مطالب، ورود مدیر، ایجاد/ویرایش/حذف مطلب، آمار و بارگذاری فایل
- پایگاه داده D1 و فضای فایل R2
- CORS محدودشده به دامنهٔ تعریف‌شده
- توکن مدیریتی امضاشده و دارای انقضا
- کد آمار خام IP را ذخیره نمی‌کند؛ از اطلاعات مکانی تقریبی ارائه‌شده توسط Cloudflare استفاده می‌کند.

## مشاهدهٔ محلی
ساده‌ترین روش: پوشهٔ `public` را در یک ویرایشگر یا سرور محلی باز کنید. برای تجربهٔ بهتر از یک سرور محلی ساده استفاده کنید؛ نیازی به اینترنت یا سرور اختصاصی برای دیدن نسخهٔ دمو نیست. گوگل فونت برای فونت Vazirmatn به اینترنت نیاز دارد؛ در صورت آفلاین بودن، فونت جایگزین نمایش داده می‌شود.

## استقرار آنلاین با Cloudflare

### 1) ساخت پروژهٔ فرانت‌اند
1. یک حساب Cloudflare بسازید و یک مخزن GitHub برای پروژه ایجاد کنید.
2. پوشهٔ `public/` را به مخزن منتقل کنید.
3. در Cloudflare Pages، مخزن را متصل کنید. Build command را خالی بگذارید و Build output directory را `public` قرار دهید.
4. پس از انتشار، دامنهٔ Pages شما شبیه `https://your-project.pages.dev` خواهد بود.

### 2) ساخت دیتابیس و فضای فایل
در ترمینال با Node.js نصب‌شده:
```bash
cd worker
npm install
npx wrangler login
npx wrangler d1 create mahyar-elektronic-db
npx wrangler r2 bucket create mahyar-elektronic-uploads
```
شناسهٔ D1 برگشتی را در `worker/wrangler.toml` جایگزین `REPLACE_WITH_D1_DATABASE_ID` کنید. سپس:
```bash
npx wrangler d1 execute mahyar-elektronic-db --remote --file=./schema.sql
```

### 3) تنظیم رازهای مدیر
رمز قوی و طولانی انتخاب کنید؛ رمز را در فایل کد ننویسید.
```bash
npx wrangler secret put ADMIN_PASSWORD
npx wrangler secret put TOKEN_SECRET
```
برای `TOKEN_SECRET` یک مقدار تصادفی طولانی و غیرقابل حدس وارد کنید. این مقادیر در خروجی عمومی سایت قرار نمی‌گیرند.

### 4) تنظیم دامنه و انتشار API
در `worker/wrangler.toml` مقدار `SITE_ORIGIN` را به دامنهٔ دقیق Pages تغییر دهید. برای نمونه:
```toml
[vars]
SITE_ORIGIN = "https://your-project.pages.dev"
```
سپس:
```bash
npx wrangler deploy
```
نشانی Worker را یادداشت کنید.

### 5) اتصال فرانت‌اند به API
در ابتدای `public/app.js` مقدار زیر را تنظیم کنید:
```js
const API_BASE = "https://your-worker.your-subdomain.workers.dev";
```
دوباره فرانت‌اند را deploy کنید.

## نکات امنیتی پیش از استفادهٔ عمومی
1. دمو را با رمز پیش‌فرض عمومی نکنید؛ پنل واقعی باید فقط با API و رمزهای محیطی کار کند.
2. قبل از باز کردن سایت برای عموم، ورود، مجوزها، CORS، محدودیت نرخ تلاش ورود، پشتیبان‌گیری و بازیابی را آزمایش کنید. برای محافظت قوی‌تر پنل می‌توان Cloudflare Access را هم فعال کرد.
3. API نمونه در حال حاضر ورود با رمز محیطی و توکن امضاشده دارد، اما محدودیت نرخ تلاش ورود در کد پیاده‌سازی نشده؛ برای انتشار عمومی باید rate limiting را در Cloudflare فعال کنید.
4. آپلود فایل در API به ۲۵ مگابایت و چند نوع MIME محدود شده است؛ برای ویدئوهای بزرگ‌تر باید روش آپلود چندبخشی/مستقیم R2 و سیاست هزینه طراحی شود.
5. مسیر فایل‌های R2 در نمونه از همان Worker ارائه می‌شود؛ برای سایت عمومی، بررسی نوع واقعی فایل، اسکن بدافزار، سیاست کش و محدودیت حجم را اضافه کنید.
6. آمار مکان تقریبی می‌تواند به کشور و گاهی شهر وابسته باشد و همیشه دقیق نیست. این نمونه IP خام را ثبت نمی‌کند. آمار اختیاری باید فقط پس از رضایت کاربر ثبت شود. قوانین محل فعالیت سایت و مخاطبان را بررسی کنید.
7. برای حریم خصوصی واقعی، سیاست حریم خصوصی، تماس مدیر، روش حذف داده و سیاست نگهداری آمار را به سایت اضافه کنید.
8. پرداخت، عضویت پولی و محافظت از فایل‌های خریداری‌شده عمداً در این نسخه اضافه نشده‌اند.

## ساختار
- `public/index.html` — صفحات و پنل نمایشی
- `public/styles.css` — ظاهر سایت
- `public/app.js` — رفتار فرانت‌اند و اتصال API
- `worker/src/index.js` — API ابری
- `worker/schema.sql` — ساختار دیتابیس
- `worker/wrangler.toml` — تنظیمات استقرار
